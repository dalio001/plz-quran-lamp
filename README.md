# PLZ Quran Lamp

A simple web app to control an Equantu SQ-122 Quran speaker lamp over Bluetooth from Chrome (Android or PC):
Quran surah/verse, reciters, translations, books, keypad buttons, volume, light, sleep timer,
azan times (copied from a Mawaqit mosque), azan sounds and switches, calculation method and place.

Open the site in Chrome, press **Connect**, choose the lamp (`XDT_...`). Close the maker's app first:
the lamp accepts one connection at a time.

`times.json` is refreshed every night from Mawaqit by the owner's PC (git_sync.ps1).
