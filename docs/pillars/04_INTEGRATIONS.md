## 🔍 Scope
- **Mawaqit:** public page `https://mawaqit.net/en/<slug>` → `confData.calendar` (12 months × day → 6 times). API needs login; page works.
  Mosque: `al-taqua-moschee-essen` (Al Taqua Moschee, Essen). Mawaqit app shows TOMORROW after Isha.
- **Web Bluetooth:** Chrome/Edge on Android, Windows, macOS, ChromeOS. Not on iPhone/iPad (Safari), not Firefox.
- **Power-on:** lamp only wakes by infrared remote. Owner's phone (vivo Y27) has no IR.
- **Sleep:** unplugged and idle, the lamp sleeps (Bluetooth off) and wakes only for the azan. On the charger it stays awake (verified 2026-11-16, 00:26-07:29, azan on time).
